### 👨‍💻 Sobre mim

Sou **desenvolvedor Python** com foco em **IA aplicada ao Direito**: automação, APIs, integrações e LLMs em produção para o setor jurídico. Sou **Desenvolvedor Júnior na Carvalho Furtado Advogados** (estagiário desde 2024, efetivado em set/2026), onde construo soluções de ponta a ponta, e estagiário de tecnologia no **Tribunal Regional do Trabalho da 3ª Região (TRT-3)**, com automação de processos.

Curso **Tecnologia** na Newton Paiva e **Direito** na Una — essa combinação me dá um diferencial raro: entender profundamente o domínio do negócio para o qual desenvolvo. Gosto de transformar processos manuais em software: workflows automatizados, integrações (Microsoft Graph, APIs judiciais), IA em produção e cloud com Azure.

### 🤖 O que estou construindo

- 🏛️ **[automacao-legalone](https://github.com/PaolloSc/automacao-legalone)**: lê o Outlook via Microsoft Graph, extrai os dados da petição com um agente do Copilot Studio e cadastra o processo no LegalOne pela API REST
- 📄 **[Honorario-cf](https://github.com/PaolloSc/Honorario-cf)**: plataforma de contratos de honorários (FastAPI + Next.js + PostgreSQL na Vercel) com emissão de NFS-e Nacional
- 📰 **[dejt_headless](https://github.com/PaolloSc/dejt_headless)**: robô que baixa o caderno do DEJT, converte para DOCX, gera sumário e entrega por WhatsApp
- ⚖️ **JurisGen**: geração de peças jurídicas com Claude API + RAG (Qdrant) sobre o SharePoint do escritório
- 🤖 **Agentes no Microsoft Teams**: Copilot Studio ligado a APIs próprias, incluindo pesquisa patrimonial e detecção de prompt injection em PDFs
- ⚽ **Bolão da Copa 2026**: React + Supabase com RLS, login Microsoft e sincronização automática de resultados
